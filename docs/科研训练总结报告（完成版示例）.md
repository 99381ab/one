# 科研训练总结报告（完成版示例）

## 一、课题名称
基于 ESP32 与 MQTT 的教室环境监测与异常预警系统设计与实现

## 二、选题背景与研究意义
随着校园数字化建设推进，教室环境（温湿度、CO₂浓度、光照）对教学体验和健康影响显著。传统人工巡检方式存在时效性差、数据离散、难以追溯等问题。物联网技术可实现低成本、多节点、连续采集与远程可视化管理，为教学场景提供数据支撑和主动预警能力。

本课题面向“物联网终端与数据应用开发”方向，围绕教室环境监测这一典型应用场景，完成从需求分析、系统设计、原型实现到实验验证的全过程训练，培养复杂工程问题分析、系统设计与工程实现能力。

## 三、研究目标
1. 设计并实现教室环境多参数采集终端，稳定采集温度、湿度、CO₂与光照数据。
2. 搭建 MQTT 数据传输链路，实现设备上报与平台接入。
3. 开发可视化监控界面，支持实时数据展示、历史查询与阈值告警。
4. 建立异常判别规则，完成“阈值超限+持续时间”联合告警机制。
5. 通过实验验证系统稳定性、时延性能与告警有效性，并形成完整总结报告。

## 四、研究内容与技术路线

### 4.1 研究内容
- 需求分析：明确教学管理人员与教室使用者的核心需求。
- 硬件设计：完成传感器与 ESP32 节点选型、连接和采集程序开发。
- 通信实现：基于 Wi-Fi + MQTT 实现数据发布/订阅。
- 平台开发：完成数据存储、接口服务与前端可视化。
- 告警策略：实现阈值规则、去抖动和持续超限判定。
- 性能测试：采样稳定性、网络时延、告警准确率测试。

### 4.2 技术路线
终端采集（ESP32 + 传感器）→ 数据封装（JSON）→ MQTT Broker 转发 → 服务端入库 → Web 可视化展示 → 异常规则引擎告警（页面提示+日志记录）。

## 五、需求分析

### 5.1 功能需求
1. 实时采集：每 10 秒采集一次环境数据。
2. 数据上报：终端自动连接网络并持续上报。
3. 数据展示：页面显示当前值、趋势曲线和节点状态。
4. 历史查询：按时间范围查询历史数据。
5. 异常告警：当 CO₂ > 1000 ppm 且持续 3 分钟触发告警；温湿度超限触发二级提示。

### 5.2 非功能需求
- 稳定性：连续运行 24 小时不崩溃。
- 时效性：端到端展示延迟不高于 2 秒。
- 可扩展性：支持多教室节点并行接入。
- 可维护性：模块化设计，便于参数调整和功能扩展。

## 六、总体方案设计

### 6.1 系统架构
- 感知层：ESP32 + 温湿度传感器 + CO₂ 传感器 + 光照传感器。
- 网络层：校园 Wi-Fi，MQTT 协议通信。
- 平台层：消息订阅服务、数据存储服务、告警服务。
- 应用层：Web 监控端（实时面板、趋势图、告警列表）。

### 6.2 关键模块设计
1. **终端采集模块**：轮询采样，异常值过滤（越界值丢弃）。
2. **通信模块**：断线重连、心跳上报、QoS1 传输保障。
3. **数据处理模块**：时间戳统一、单位标准化、入库前校验。
4. **告警模块**：阈值判断 + 持续时间窗口。
5. **可视化模块**：卡片化指标展示 + 折线趋势图。

### 6.3 方案可行性说明
- 技术可行：ESP32 与 MQTT 生态成熟，开发门槛适中。
- 经济可行：硬件成本低，适合课程实践。
- 工程可行：模块划分清晰，4 周内可完成原型与测试。

## 七、实现过程

### 7.1 第 1 周：调研与选题
- 查阅物联网环境监测、校园空气质量、MQTT 应用相关资料。
- 比较 ZigBee、LoRa、Wi-Fi 三类通信方案后，结合场景选择 Wi-Fi。
- 明确研究边界：以“教室环境监测 + 异常预警”为核心，不扩展复杂联动控制。

### 7.2 第 2 周：问题分析与系统设计
- 完成系统分层架构和接口定义。
- 制定数据格式：`device_id`、`timestamp`、`temp`、`hum`、`co2`、`lux`。
- 设计告警规则与参数阈值，并形成测试用例草案。

### 7.3 第 3 周：原型开发与实验
- 完成 ESP32 端采集与 MQTT 发布程序。
- 实现服务端订阅、数据入库与接口输出。
- 完成前端页面开发（实时看板、趋势曲线、告警列表）。
- 开展联调，修复断网重连与重复告警问题。

### 7.4 第 4 周：总结与汇报
- 按测试方案完成功能测试与性能测试。
- 汇总实验数据，形成图表与结论。
- 完成课程汇报材料与总结报告。

## 八、实验设计与结果分析

### 8.1 测试项目
1. 采集稳定性测试：24 小时连续采集，统计丢包率。
2. 端到端时延测试：采集到页面展示的平均延迟。
3. 告警准确性测试：模拟超阈值场景，统计误报与漏报。
4. 并发接入测试：多节点同时上报时平台响应情况。

### 8.2 结果汇总（示例）
- 24 小时采集共 8640 条记录，丢包率约 0.9%。
- 端到端平均时延约 1.3 秒，满足设计目标。
- 告警准确率约 95.6%，主要误差来自传感器瞬时抖动。
- 4 节点并发上报下平台运行稳定，页面刷新正常。

### 8.3 结果分析
系统总体满足课程任务要求，验证了“物联网终端采集—网络传输—平台处理—可视化告警”的完整链路。当前不足主要体现在传感器抗干扰能力和告警策略精细化程度。后续可通过滑动均值滤波、分级阈值和多条件联合判定进一步提升鲁棒性。

## 九、结论与展望
本课题完成了教室环境监测与异常预警系统的设计与实现，达成了预期研究目标：实现多参数采集、稳定上报、可视化展示和规则告警，并通过实验验证了系统可用性。通过本次科研训练，进一步提升了文献调研、问题分析、系统设计、工程实现与报告表达能力。
